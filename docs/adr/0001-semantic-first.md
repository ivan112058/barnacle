# 语义优先：样式作用于裸元素，而非类名

barnacle 采用语义优先架构——样式直接作用于裸的语义元素（`button`、`input`、`table`、`dialog`、`details`、`progress`）与 ARIA 属性（`[role="alert"]`、`[role="switch"]`、`[role="tablist"]`），类名只保留给没有语义锚点的场合：语义变体走 `data-variant`，视觉修饰与布局走 `bn-` 类名。

被否决的替代方案是纯类名 API（`.bn-btn`、`.bn-card`），这是绝大多数 CSS 库的做法。选语义优先是因为它让**正确写法成为默认写法**：使用者写标准 HTML 就得到正确外观，而不是需要逐处记得添加类名。代价是本库成为全局样式，无法被部分采用——引入即接管整页。这是刻意接受的取舍，必须写在文档第一段。
