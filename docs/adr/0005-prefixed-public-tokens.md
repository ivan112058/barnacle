# 公共令牌加 `bn-` 前缀，内部变量用 `--_`

barnacle 的公共主题令牌一律加 `bn-` 前缀（`--bn-background`、`--bn-main`、`--bn-border-color`），内部实现变量用 `--_` 前缀（`--_variant-color`）。

这与两个参考源都不同——oat 和 neobrutalism.dev 都不给令牌加前缀，直接用 `--background`、`--main`、`--border`。我们偏离是因为这些名字在任何项目里都极易与使用者自己的变量**静默撞车**：CSS 自定义属性冲突不会报错，只会让某一边的设置无声失效，排查成本极高。前缀化的公共令牌是作为产品发布的 CSS 库的通行做法（Bootstrap、Pico、Bulma 皆如此）。

注意裸元素本身**不**需要前缀——语义优先下它们没有类名。前缀只加在我们发明的名字上：类名、自定义元素、公共令牌。
