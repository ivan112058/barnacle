# `@layer` 层顺序是公共契约

拼接产物的第一行固定声明：

```css
@layer theme, base, components, animations, utilities;
```

这条声明是**公共契约**，不是内部实现细节。因为 CSS 级联层的规则是：未分层的样式自动胜过任何分层样式。这意味着使用者无需理解 `@layer`、也无需提高选择器权重，只要不写 `@layer` 就能覆盖本库的任何样式。把声明放在产物第一行且因此不可省略 `00-base.css`，正是为了让这条保证无条件成立。

若将来新增层，**只能追加在末尾**，插队会改变既有覆盖关系的优先级。
