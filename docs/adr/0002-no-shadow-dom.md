# 自定义元素使用浅 DOM，不使用 Shadow DOM

barnacle 的交互组件（`<bn-dropdown>`、`<bn-tabs>`、`<bn-taginput>`）是**浅 DOM** 自定义元素，子树留在主文档中，由 `src/css/` 里的普通类名与公共令牌直接样式化。

自定义元素的常规做法是配 Shadow DOM 做样式封装，但在这里封装是纯损失：本库的产品就是样式，Shadow DOM 会把 `bn-` 类名和 `--bn-*` 令牌挡在组件之外，使用者既无法用令牌主题化组件内部，我们也无法复用同一套样式规则。放弃封装的代价是需要自行管理类名冲突，而 `bn-` 前缀已经处理了这一点。
