# 硬阴影分三档，而非单一阴影

barnacle 提供 `--bn-shadow-sm` / `--bn-shadow-md` / `--bn-shadow-lg` 三档阴影，全部由 `--bn-shadow-x/y` 两个偏移值经 `calc()` 派生，因此改一个基准值即可整体缩放层次感。

主要参考源 neobrutalism.dev 只提供单一 `--shadow`，我们偏离它是因为单一阴影会**系统性地**导致「层级坍缩」：当每张卡片、每个按钮、每个提示都用同等强度的阴影时，界面失去层次，而这是库无法在使用者侧修复的缺陷——使用者能改数值，但改变不了「只有一个档位可用」这个前提。三档而非更多，是为了让选择足够少以至于不需要思考。
