title: "轻提示"

---

轻提示是没有标记的组件。没有元素要记，也没有类要选：`bn.toast()` 造出消息，把它放进视口角落里固定的
一摞里，然后再把它收走。它同时也是架构留给自己规则的反例——自定义元素包住的是内部状态与生命周期，而一条
消息两者都没有，所以轻提示是挂在全局 `bn` 对象上三个入口背后的一个普通模块（spec §9）。

<!-- fence:0 -->

点其中任何一个按钮，消息就出现在**页面**右下角，而不是预览面板里面：那一摞固定在视口上，而这正是轻提示的
全部意义——它跟着访客读完长页面，而不是待在文档里它被创建的那个位置。只有消息本身是点击目标；承载它们的
那条带子把点击透传给下面的页面，所以一条正在消失的消息永远不会吞掉输入。那段围栏里的处理器是行内的，因为
渲染层是用 `innerHTML` 注入示例标记的，在那里 `script` 元素是惰性的；真实代码里你会用 `addEventListener`
挂上这个调用。如果预览的处理器在你的环境里跑不了，同样的入口在控制台里也能用：`bn.toast('hi')`。

### API

| 入口 | 签名 | 作用 |
|---|---|---|
| `bn.toast` | `toast(message, options?)` → `Element` | 显示一条消息，并给它装上自动消失。 |
| `bn.toast.el` | `el(message, options?)` → `Element` | 造出并显示一条，但**不**装定时器：生命周期归调用方。`clear()` 仍然能关掉它。 |
| `bn.toast.clear` | `clear()` → `number` | 关掉每一条活着的消息，并报告它开始关掉了多少条。幂等——第二次调用是空操作，返回 `0`。 |

<!-- fence:1 -->

| 选项 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `message` | 字符串、数字或 `Node` | `''` | 字符串按**文本**插入，从不解析成标记；`Node` 则直接追加。 |
| `variant` | `success` / `warning` / `danger` / `error` | 无 | 变成 `data-variant`，和库中别处完全一样：含义是属性，永远不是类。任何别的值就是没有语义变体。 |
| `duration` | 毫秒，≥ 0 | `5000` | `0` 表示「不要自己消失」。负数、非有限或非数字的值会在动手建任何东西之前抛 `TypeError`，所以写错的时长不可能悄悄产出一条永不消失的消息。 |

### 计时与消失

关于一条会自己消失的消息，有三件事，按它们有多容易被搞错的顺序排列。

默认寿命是 **5000 毫秒**，每次调用都可以覆盖它。轻提示不是通知中心：没有重试、没有排队、没有重放，所以
`bn.toast` 是一条普通的调用，配一个普通的答案。

那一摞从不挡住页面。容器是一个固定的盒子——因此它压在右下角任何东西上面——但它是 `pointer-events: none`，
每条消息自己把指针事件重新打开。只有消息是目标；它们之间的空隙以及带子的其余部分，把每一次点击都透传给
下面的页面。一次被动的消失永远吞不掉输入。

退场是一段动画，所以定时器一响，元素并不会被立刻移除：`toast.clear()` 给每条消息打上 `data-closing`，
并向 `getComputedStyle` 询问它即将播放的 `animation-duration`。正是这次读取，让任何时长都不会被写两遍
——动画归 CSS 所有，JS 向它要。

### 减少动效

入场与退场都声明在 `prefers-reduced-motion: no-preference` 块里，所以要求减少动效的访客拿到的不是一段
被停用的动画——那条规则干脆不存在。消息照样出现、照样在它的时长里待着、也照样离开；而且因为此时计算出的
`animation-duration` 是 `0s`，它立刻就走，而不是去等一段永远不会播放的动画。

### 为什么它不是自定义元素

自定义元素是为那些有状态要保、有生命周期要活下来的组件存在的：解析、升级、重连、断开（ADR-0002、
spec §9）。一条轻提示只有一样状态——那个会删掉它的定时器——而那个定时器属于这次调用，不属于元素；元素
本身没有什么可观察，也没有什么要重新初始化。把它包进 `<bn-toast>` 买不到任何行为，却要花掉一个自定义
元素名字、一个 shadow DOM 问题，以及一条升级路径。所以标记词汇里没有 `bn-toast`，而全局表面上唯一不是
注册钩子的东西就是 `bn.toast`。

### 覆盖它

不分层的 CSS 直接赢，就像它对库发布的每条规则都赢一样（ADR-0006）。在那之后，槽位是令牌。
`--bn-secondary-background` 是表面，没有语义变体时 `--bn-border-color` 是边框，`--bn-press` 是消息淡
出时行进的距离，而 `--bn-transition` 是两段动画各自的时长。要覆盖就在 `:root` 上覆盖，不要在包裹元素上：
派生令牌在它被声明的地方就已经替换完毕，这也正是为什么边框取到语义变体的颜色、硬阴影却保留页面自己的阴
影颜色——阴影令牌是在 `:root` 上构建的，在那里它的颜色已经定死。
