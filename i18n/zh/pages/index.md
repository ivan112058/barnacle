**Barnacle** 是一套语义优先的 Neubrutalism UI 库。你写那个本来就表达了你意图的 HTML 元素——
`<button>`、`<dialog>`、`<table>`、`<progress>`——Barnacle 让它好看。没有类名 API 要学，没有
shadow DOM，没有运行时依赖。

先从[组件](/zh/components/)目录看起，读[使用方式](/zh/usage)把库放进页面，再看
[自定义主题](/zh/customizing)用设计令牌给它换皮。
