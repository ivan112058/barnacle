title: "Barnacle"
description: "A semantic-first Neubrutalism UI library in pure CSS — zero runtime dependencies."
---

**Barnacle** is a semantic-first Neubrutalism UI library. You write the HTML element that
already means what you mean — `<button>`, `<dialog>`, `<table>`, `<progress>` — and Barnacle
makes it look right. There is no class-name API to learn, no shadow DOM, no runtime
dependency.

Start with [Components](/components/) for the catalogue, read [Usage](/usage) to drop the
library into a page, and [Customizing](/customizing) to retheme it with design tokens.
