# 12: Form

**What to build:** 全部裸表单元素成体系可用：输入框、下拉、多行文本、复选、单选、字段集、标签。校验状态只在**用户真的交互过之后**才出现——一进页面满屏红框是最常见的表单设计错误。

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] 裸 `input` / `select` / `textarea` / `checkbox` / `radio` 呈正确外观，尺寸与排版成体系
- [ ] `fieldset` / `label` 就位，字段组有可辨的边界与标题层级
- [ ] 校验状态用 `:user-invalid` 触发（交互后），**不出现**:invalid 导致的初始红框
- [ ] 校验语义走 `data-variant`，与外观修饰不混用
- [ ] 校验态**不改变边框宽度**，避免栅格重排
- [ ] 焦点环对所有控件可见
- [ ] 实测 `:user-invalid` 在目标浏览器可用；不可用则记录兜底方案并落地
- [ ] 文档站出现「Form」页，含各类控件与校验态示例

**验证方式**

1. 直接打开 Form 页，确认没有任何控件在未交互前呈现错误态。
2. 逐个控件输入非法值后再失焦，确认错误态出现。
3. 逐一读取校验前后与聚焦前后的边框宽度，确认全部一致。
4. 记录 `:user-invalid` 的实测结果（对应 spec §14 的实测要求）。
