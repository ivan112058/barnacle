# 13: Table

**What to build:** 裸表格呈 Neubrutalism 外观：硬边框、表头分隔清晰、斑马或分隔线二选一、窄屏不撑破布局。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 裸 `table` / `thead` / `tbody` / `th` / `td` 呈正确外观，边框不重叠双线
- [ ] 表头与表体视觉层级可辨，不靠降低对比度实现
- [ ] 窄屏下表格整体可横向滚动，不撑破页面布局
- [ ] 数字与文本列的对齐规则明确且可预期
- [ ] 焦点与选中态（若实现）不改变边框宽度
- [ ] 文档站出现「Table」页

**验证方式**

1. 把窗口缩到手机宽度，确认页面不出现横向溢出滚动，而表格自身可滚。
2. 确认相邻单元格边框不出现双线或错位。
3. 在暗色下确认表头分隔仍清晰。
