# 06: 基础层与层顺序契约

**What to build:** 裸语义 HTML 一进来就是 Neubrutalism 的样子。不写任何类名，`h1`–`h6`、段落、列表、引用、代码、分隔线、高亮就各自站对了位置。这是「语义优先」的第一次真实验证。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] `00-base.css` 第 1 行是 `@layer` 声明，层顺序与 01 号票的层清单一致（ADR-0006）
- [ ] 裸 `h1`–`h6`、`p`、`ul`/`ol`、`blockquote`、`code`、`pre`、`hr`、`mark` 直接呈现正确排版与外观
- [ ] `body` 拿到背景色、前景色、字体族与字重
- [ ] 样式不依赖 JS：无脚本时外观完整正确（§3 不变量 6）
- [ ] 未压缩产物中无 `!important`
- [ ] 文档站出现「Typography」页，用一个代码围栏展示全部裸元素

**验证方式**

1. 在禁用 JavaScript 的浏览器里装载该页，确认外观完整。
2. 确认未压缩 CSS 的第 1 行仍是 `@layer` 声明，且层顺序与 01 号票记录的清单逐项一致。
3. 在页面里覆盖一个颜色令牌，确认无需 `!important` 即可生效（层顺序可被使用者覆盖）。
