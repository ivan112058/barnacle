# 07: Button 与交互契约

**What to build:** 库的第一个组件，也是整套交互几何的定义处。裸 `button` 与 `a` 呈按钮外观，悬停上浮、按下落回、焦点环可见且不吞掉硬阴影。**到这一步 Neubrutalism 风格是否成立即可见分晓。**

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 裸 `button` 与 `a` 呈按钮外观；`.button` 类名保留给无语义锚点的场合（ADR-0001）
- [ ] 交互几何完整：静止用中档阴影、悬停按 `--bn-shadow-lift` 上移并放大阴影、按下朝阴影方向落下且阴影收拢
- [ ] 焦点用 `outline` + `outline-offset` 实现，画在硬阴影之外（ADR-0003）；**绝不出现 `outline: none` 而无替代**
- [ ] `prefers-reduced-motion: no-preference` 块内限定动效，事后禁用不算
- [ ] 语义变体走 `data-variant`，视觉修饰走 `bn-` 类名（描边 / 幽灵 / 尺寸 / 禁用），两者不混用
- [ ] 悬停只改边框颜色，**绝不改边框宽度**
- [ ] 按钮组就位
- [ ] 无脚本时外观完整，仅失去交互
- [ ] 文档站出现「Button」页，含可运行示例与 `data-variant` 选项说明

**验证方式**

1. 在页面上悬停与按下，确认位移距离与阴影增量相等（物体真的「抬离」阴影）。
2. 键盘 Tab 到按钮，确认焦点环完整可见、且没有被厚边框或阴影吞掉。
3. 把系统动效设为「减少动态效果」，确认动效消失而外观不变。
4. 逐项确认悬停前后边框宽度计算值一致。
5. 08 号票的浏览器验收台会把这些不变量固化成断言，本票先手工确认一遍。
